# fatrat-warforum-free

A [FatRat](http://fatrat.dolezel.info) plugin, `warforum-free`, for
webshare.cz links such as `https://webshare.cz/#/file/5ShDjqTwK2/ddo02-7z`.

Install: Settings -> Extensions -> Repositories -> Add, give it this
directory (or its git URL), install `warforum-free`, restart FatRat.

The plugin talks to webshare.cz only and runs with your user privileges.
